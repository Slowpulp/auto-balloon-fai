# 两表 FAI 检验工作簿

## 工作表契约

默认工作簿恰好包含两个工作表，顺序为：

1. `FAI检验记录`
2. `检具代码`

不得增加辅助、说明、日志或审计工作表。需要公式辅助数据时，优先直接从台账生成自包含公式，或放在保留工作表的非打印辅助区域；所有跨表引用必须指向实际存在的工作表。

每张表设置明确打印区域、横向方向和宽度适配。主检验表跨物理页时重复列标题。除非用户明确要求，`fitToWidth=1` 不应被描述为“物理总计两页”。

## FAI检验记录

至少包含：

- 零件号、图纸版本、材料、零件名称。
- 生产批号、数量、AQL、检验数量、发布状态。
- NO.、图纸要求、位置/页次、上偏差、下偏差。
- 一个或多个实测值输入栏、检具代码、结果和备注。
- 编号特性之后的未编号要求区，NO. 留空。
- 结论、检验员、检验日期、复核和日期。

编号行必须与气泡 ID 完全一致。不要填造实测值或签署信息。输入单元格应明显可编辑，缺少抽样数或实测时不得显示合格。未注公差的备注至少列明标准、等级及待批准状态，使用户不依赖被删除的“公差依据”页也能理解来源。

实测列数量由用户、模板或抽样上限决定；若均未指定，可采用 5 列并把抽样数限制为 1～5。需要更多样本时扩展实测列、公式、验证和打印布局，不能截断数据。属性输入词表默认使用 `OK/NG/N/A/HOLD`，项目规范另有词表时以其为准。

未编号的明确外观要求可使用 VI 属性检验；如果验收准则清楚且不存在冲突，可保持待检输入状态。验收准则不完整则标 OPEN，存在冲突则标 HOLD。总体结论只有在所有编号项、未编号要求、实际检具和签署前提均满足时才能形成正式 OK。

混合单位必须逐行标识，不得静默换算。数值显示精度和舍入规则应匹配图纸、公差或测量系统分辨率。

## 判定顺序

公式按以下优先级处理：

1. HOLD。
2. 特性定义/公差是否完整。
3. 抽样数是否合法。
4. 已填样本数是否与抽样数匹配。
5. 输入类型是否合法。
6. 数值或属性判定。

数值项使用 `MIN(样本) >= LSL` 且 `MAX(样本) <= USL`，边界包含等号。属性项使用受控词表，任一 NG 即 NG，要求数量全部为 OK 才可 OK。默认公差项输出“暂定OK/暂定NG”，OPEN 项保持“待确认”。逻辑必须由台账的 mode/status/limits 驱动，不得按固定特性号写特殊分支。

删除工作表后，必须静态扫描全部公式引用并在 Excel 或等效目标引擎中强制重算；普通缓存值和简单错误字符串扫描不足以证明公式有效。

## 检具代码

至少包含：

- 检具代码、检具类别/名称、适用气泡号。
- 项目所需量程/适用范围。
- 检具型号、可测量范围、资产编号、分辨率/准确度、检具有效日期。
- 状态/说明。

代码和推荐范围属于检验策划，不能冒充现场实际设备。检具型号、实际量程、资产号、分辨率/准确度和有效日期在模板阶段保持独立空白字段；空白不表示不适用。实际放行前需核对量程覆盖、测量能力、校准证书和有效期。
